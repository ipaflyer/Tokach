# Журнал итераций «Обвод»

## Итерация 0 — первый playable

**Что было не так.** Концепция на бумаге, в репозитории жил «Толкач».

**Что изменено.** Забег: черта, интерьер, отмирание, тень. Цветной canvas, HUD, самопроверки, `?demo=1`, environment.json, луп 10 итераций.

**Проверка environment.** Node selfcheck: 7/7. Chrome headless зависает на rAF (скриншот до JS). Computer Use (DISPLAY=:1): после фикса `const G` карта видна — фиолетовые стены, золотые фонари, зелёные сгустки, бирюзовая черта. WASD пишет след.

**Самое слабое.** Смерть в оверлее роняла JS (нет overlayTitle/overlayText). Отмирание слишком рано для медленного первого забега.

## Итерация 1 — не падать и дать время на первый контур

**Что было не так.** `const G` в rules.js и app.js как глобальные скрипты — SyntaxError, чёрный canvas. `showOverlay` писал в null. Отмирание 13 с / 8.6 съедало вход, пока тестировщик учился ходить.

**Что изменено.** Geom вместо G в rules. ID у заголовка/текста оверлея + защита от null. Delay отмирания 18 с, скорость 7.4.

**Почему.** Без кадра нет плейтеста. Без оверлея конец забега ломает цикл. Без запаса по отмиранию нельзя проверить замыкание.

**Проверка.** Node selfcheck 7/7. Computer Use: дом, черта, движение живые.

**Самое слабое.** Контур в живой сессии ещё не успели закрыть до отмирания; периметр/площадь не калиброваны глазом; тень второго забега не смотрели.
