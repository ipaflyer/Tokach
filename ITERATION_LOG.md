# Журнал итераций «Обвод»

## Итерация 0 — первый playable

**Что было не так.** Концепция была на бумаге. В репозитории жил карточный «Толкач». Луп крутил дизайн, а не игру.

**Что изменено.** Собран забег: черта, интерьер (печать / выжигание / захват), отмирание, тень прошлого маршрута. Карта-дом, цветной canvas, HUD длины черты. Самопроверки правил и `?demo=1`. Environment: static HTTP на 8765.

**Почему.** Без playable нельзя проверить гипотезу, баланс и красочность.

**Проверка environment.** Следующий шаг этой итерации: Chrome screenshot + selfcheck.

**Самое слабое.** Ещё не видали живой кадр; калибровка площади/длины/отмирания может быть жестокой или пресной.
